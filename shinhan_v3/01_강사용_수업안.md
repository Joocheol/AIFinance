## 3. 운영 주의

- **비밀**: `.env`에만(연락처·DB 비밀번호·키). 채팅·화면에 보이면 즉시 교체. 키트 `CLAUDE.md`가 Claude에게 `.env`를 열지 말라고 지시한다.

같은 날 더 시험한 것: "What if the stock price falls by half?" → 벡터 ✓ Downside Scenario / "주가가 반토막 나면 원금은?" → 벡터 ✓ -60% 만기 지급 예시 / "Is this product suitable for retirees…" → 벡터 제목 청크 "Investor Suitability"만 / "Who decides the value if the index is no longer published?", "만기 전에 팔 수 있나? 손해는?" → 벡터 ✗. 키워드는 모두 없음.
벡터 상위가 같은 문단(다른 공시)으로 채워지는 것은 정상: 상품 이름만 다른 위험 고지가 공통 문구로 합쳐지지 않음.
