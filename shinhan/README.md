# 신한은행 FE/RM AI Finance 실습 — Claude판

- 일정: **2026년 11월 28일, 12월 5일** 각 3시간 / 장소: 연세대학교
- 참가자: 신한은행 FE/RM, **Claude Pro($20) 개인 구독**, 개인 노트북, Azure 무료 계정(사전 과제)
- 원본 수업안: Dropbox `JPMorgan_424B2_AI_Finance_수업자료` (ChatGPT+Excel판). 이 폴더는 그 골격(분모·근거·검증·고객 설명)과 평가 기준을 유지하고, **도구를 Claude로 바꾸고 직접 해 보는 경험을 최대한 늘린** 버전이다.

## 수업을 마치면 참가자는

1. 공개 공시에서 상품 조건을 찾아 **AI 추출 결과를 원문과 대조**한다.
2. **문서 수·상품 수·원금 확인 상품 수**를 구분하고, 분모를 밝혀 말한다.
3. 조건부 쿠폰·조기상환·배리어/버퍼·발행자 신용위험을 **고객에게 설명**한다.
4. Claude의 여러 도구(프로젝트, 분석·파일 생성, 아티팩트, 커넥터, Claude Code)와 클라우드(Azure)를 **직접 써 본다**.
5. 근거가 부족하면 **결론을 보류**한다.
