**리허설에서 나온 Windows 함정**
- **실행 정책**: Windows 기본값(Restricted)은 `.ps1` 실행을 거부합니다. 활동지대로 `powershell -ExecutionPolicy Bypass -File ...`(그 명령 한 번만 허용)를 쓰게 하고, `Set-ExecutionPolicy`로 PC 설정을 바꾸게 하지 않습니다.
- **한글 깨짐**: Windows PowerShell 5.1은 BOM 없는 UTF-8 `.ps1`의 한글 메시지를 깨뜨립니다. 프롬프트에 "출력 메시지는 영어로"를 넣은 이유입니다.
- **환경변수**: 학생이 Desktop 터미널에서 설정한 `SEC_USER_AGENT`는 Claude(Code 탭)가 보지 못합니다. 그래서 Claude는 만들고, 실행은 학생이 터미널에서 합니다.

|---|---|---|
| 출처·원문 근거 | 30 | 활동 2 오류 판정표, 활동 7 주장 대조표 |
| 상품 단위·분모 | 25 | 활동 5 분모 대조표, 활동 6 표 |
| 조건·지급방식 | 25 | 활동 9·10 결과 |
| 한계가 명확한 고객 설명 | 20 | 활동 10-2 설명서, 발표 |

감점: 근거 없는 숫자, 예비값을 최종 집계에 사용, 금액 결측을 0으로 대체, 높은 쿠폰만으로 우수 상품 선정, 가격·가치 차이를 순이익으로 표현.

## 5. 운영 주의

- **Claude Pro 사용량**: 활동마다 새 대화. 큰 파일(Excel 통합문서 8.9MB)을 Claude에 올리지 않게 한다. CSV는 2.7MB 경량본만.
- **SEC 접속**: 강의실 전체가 IP 하나로 보인다. 활동 1(브라우저 열람)은 문제없고, 활동 11만 조별 순차. 403/429는 즉시 전원 중단, 우회 금지.
- **개인정보**: 연락처 이메일은 참가자 노트북의 환경변수에만. 채팅·파일·로그에 쓰지 않는다.
- **Azure 비용**: 참가자 서버는 쓰지 않으면 0개로 줄어든다(깨어날 때 약 5초). 강사 공용 서버는 수업 중에만 `minReplicas=1`, 끝나면 0 또는 삭제.
- **알려진 데이터 공백**: Wells Fargo 판매 형식 확정 공시 241건이 상품 표에 없다(검토 대기). 판매 채널 질문이 나오면 이 한계를 먼저 말한다.
