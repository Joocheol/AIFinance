
## 부록 (선택). SEC에서 원문을 직접 받기

오늘은 Dropbox에 미리 받아 둔 원문을 썼습니다. 원문을 SEC에서 직접 받으려면 규칙이 있습니다: 연락처가 담긴 User-Agent, 초당 10건 이하, 403·429면 즉시 중단. 강의실 전체가 IP 하나로 SEC에 가므로 수업 중에는 강사가 부르는 조만 1건씩 받습니다.

```
jpm_kit/sec_fetch 안내를 읽고, SEC 원문 1건을 받는 스크립트를 만들어줘(Windows면 PowerShell 5.1, Mac이면 curl).
연락처는 환경변수 SEC_USER_AGENT에서 읽고, 없으면 요청 없이 LOCAL_PREFLIGHT_CONTACT_MISSING을 출력하고 멈춰.
1초 대기, 403·429면 즉시 중단, 파일 크기와 SHA-256 출력, 출력 메시지는 영어. 실행은 하지 마.
```

실행은 내가 Desktop 터미널에서: Windows `powershell -ExecutionPolicy Bypass -File .\sec_fetch.ps1 <URL>` / Mac `sh sec_fetch.sh <URL>`.
같은 날 받은 파일은 누구나 같은 해시가 나오지만, 10월에 받은 파일과는 다릅니다. SEC가 HTML 끝에 붙이는 한 줄이 바뀌기 때문입니다. 그래서 수집 시점과 해시를 함께 기록합니다.
