# AI Finance 1 사전 준비 (11월 28일 수업 전까지, 약 35분)

이 수업에서는 **SEC에서 JPMorgan 공시 원문을 직접 받고 → 텍스트로 바꾸고 → 내 Azure DB에 넣고 → SQL과 임베딩으로 검색**합니다. 수업 시간을 설치가 아니라 실습에 쓰기 위해 아래를 미리 해 옵니다. **개인 노트북**을 권합니다(회사 노트북은 설치·외부 접속이 막혀 있을 수 있음).

| # | 할 일 | 확인 방법 |
|---|---|---|
| 1 | 이미 쓰고 있는 **VS Code**와 **Claude Code** 확장이 최신인지 확인 (확장 화면에서 "업데이트" 버튼이 보이면 누르기). Claude Code 패널에 "안녕"을 보내 답이 오면 성공 | Claude Code가 답한다 |

| 3 | 작업 폴더: **문서(Documents)** 안에 `jpm-class` 폴더 → VS Code **파일 → 폴더 열기** | VS Code 탐색기에 `JPM-CLASS` |

**요청 1 (Claude Code 패널에 그대로)**
```
Python 패키지 관리자 uv 가 설치되어 있는지 확인하고, 없으면 공식 설치 방법으로 설치해줘.
설치 후 `uv run --python 3.12 python --version` 을 실행해 결과를 보여줘.
```

**요청 2**
```
Azure CLI 가 설치되어 있는지 확인하고, 없으면 이 운영체제에 맞는 공식 방법(Windows: winget, Mac: Homebrew)으로 설치해줘.
설치 후 `az version` 결과를 보여줘. 로그인(az login)은 내가 직접 할게.
```

> Claude Code는 명령을 실행하기 전에 허락을 묻습니다. 무엇을 하려는지 읽고 허락합니다.
> 수업은 **공개된 SEC 공시**만 다룹니다. 회사 자료·고객 정보는 Claude나 Azure에 올리지 않습니다.
> `.env`는 비밀 파일입니다(이메일, 이후 DB 비밀번호와 키). 채팅에 붙여 넣거나 Claude에게 열어 보라고 하지 않습니다.
> SEC는 자동으로 공시를 받는 프로그램에 연락처를 밝히라고 요구합니다. 이메일은 SEC에 보내는 요청의 머리글에만 쓰입니다.
