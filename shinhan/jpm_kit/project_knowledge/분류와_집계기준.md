# 분류와 집계 기준

현재 대표 분류는 V2 계약조건 근거 규칙 분류(잠정)이며, 상세 검증은 계약조건_분류검증보고서.md를 따른다. 아래 상품명 키워드 분류표는 V1 이력 설명이다. 문서·식별·금액 분모 기준은 계속 적용한다. `eligible_candidate`는 사람의 전수 검토 완료나 실제 결제 완료를 뜻하지 않는다. 원본과 정규화 텍스트, 필드 근거, 검토대기 목록을 함께 보관한다.

## 모집단과 분모

- 엄격한 본기간 제출목록: 두 CIK의 2025-10-01~2026-09-30 `424B2`, accession 중복 제거 22,753건. CIK별 원자료 44,454행과 구별한다.
- 인접월 `424B2` 3,010건: 본기간 예정 발행일에 해당하는 상품의 경계 누락 점검용이다.
- `424B3` 1,200건과 `424B8` 37건: 후속 정정·대체 가능성 점검용이다. 엄격한 424B2 문서수나 신규 상품 모집단에 합산하지 않는다.
- 상품표: 원문에서 식별한 최종 424B2 상품 단위다. 예정 issue date가 본기간 안인 행은 `products_in_period.csv`, 수집 범위 전체의 식별 결과는 `products_observed.csv`에 보관한다.
- 원금 필드 커버리지: 식별 상품 중 통화와 원금을 추출한 상품의 비율이다. 전체 발행시장 금액 커버리지가 아니다. 미식별 문서에 들어 있을 상품 수는 추정하지 않는다.

## 문서 분류

| 값 | 기준과 처리 |
|---|---|
| preliminary_pricing | preliminary/subject to completion 등 명시 표지. 확정 상품·원금 집계에서 제외 |
| final_pricing | pricing supplement와 가격결정·trade 날짜 등 최종 조건 표지. 이후 상품 식별·조건 검사를 별도로 수행 |
| common_supplement | 일반적으로 적용되는 조건·향후 수시 발행 설명 등 공통 문서. 특정 상품 발행으로 세지 않음 |
| other_offering_review_required | 일반 회사채 등의 별도 offering이거나 규칙상 공통 문서로 단정할 수 없는 경우 |
| uncertain_or_other | 위 기준으로 확정하지 못한 경우. 원문 검토 필요 |

공통 설명서에 개별 발행금액을 배정하지 않는다. 최종 pricing 문서라도 단일 상품이라고 가정하지 않는다. 문서 분류의 최종 표지는 상품 조건·현재 버전·실제 결제의 확인과 다른 판단이다.

## 상품명 기반 잠정 분류와 현금흐름

상품 구성비는 상품명 기반 잠정 분류다. 제목의 Contingent 또는 Review Notes → Buffer → Barrier 순서로 우선 분류한다. 아래 경제적 설명은 원문 확인을 위한 안내이며 계약조건 검증 완료를 뜻하지 않는다. 10,410개 전수 사람 검토는 미완료이고 표본 194항목을 전체 정확도로 환산할 수 없다. 비교 분모는 2025Q4 2,499개, 2026Q3 2,681개다.

| 값 | 뜻과 주의 |
|---|---|
| contingent_income | 조건부 이자/Review Notes 계열 후보. 쿠폰 조건·주기·관찰·memory를 별도로 확인 |
| buffered_return | 손실 buffer가 있는 수익참여 계열. buffer 10%와 barrier level 90%는 같은 필드가 아님 |
| barrier_return | 원금손실 barrier 계열. 만기만 관찰하는지 기간 중 관찰하는지 원문 확인 |
| return_enhancement | 상승 참여·수익확대 계열 후보 |
| callable_fixed_income | 콜러블 고정금리 계열. 발행자의 임의콜과 시장조건 자동콜을 구별 |
| callable_step_up_income | 단계별 금리. 하나의 고정 연율로 합치지 않음 |
| callable_fixed_floating_income | 초기 고정금리에서 변동금리로 전환되는 구조. 초기 금리를 전체 만기의 확정 금리로 취급하지 않음 |
| callable_zero_coupon | 중간 쿠폰 없이 할인발행하는 콜러블 채권. 액면 원금과 공모가격 총액이 크게 다를 수 있음 |
| other_or_uncertain | 세부 구조를 확정하지 못한 식별 상품. 비교·해석에 주의 |

`single`은 단일 기초자산, `worst_of`는 가장 부진한 기초자산 기준, `basket`은 바스켓 연계다. 문서 안의 독립 상품 여러 개를 바스켓으로 묶지 않는다. 복합·미확정 구조는 별도로 검토한다.

쿠폰 `conditional`은 조건부, `fixed`는 고정, `step_up`과 `fixed_floating`은 기간별 구조, `none`은 쿠폰 없음, `uncertain`은 미확정이다. 무쿠폰 채권의 쿠폰 필드 빈칸은 만기 수익률이 0이라는 뜻이 아니다. `memory=yes`는 미지급 이자 추후 지급 조항을 찾은 경우이며, 미검출은 `no`의 증명이 아니다.

## 식별·버전·다상품

CUSIP 체크섬과 `발행자|CUSIP|예정 issue date|maturity date`를 기본 식별키로 사용한다. 동일 키와 같은 조건의 여러 최종본은 하나만 합산하고 관련 accession을 보존한다. 조건이나 원금이 달라지거나 동일 CUSIP에 날짜가 달라지면 정정·증액·재개발행 검토 대상으로 분리한다.

후속 관련 서식에서 같은 CUSIP이 나타나면 기존 424B2 상품의 정정·대체 가능성을 검토한다. 확인하지 않은 `superseded` 상태는 만들지 않는다. 버전 연결 후보와 원문 링크는 별도 CSV에 남긴다.

다상품 문서는 독립 offering이라는 명시, 상품 라벨별 금액, CUSIP·cap 표가 서로 연결될 때만 분리한다. 원금을 상품 수로 균등 분할하지 않는다. 분리하지 못한 문서는 검토대기이며 상품 수를 임의 추정하지 않는다.

## 금액·단위·관찰

`principal`은 원문의 액면 총원금, `public_offering_amount`는 Price to Public 표의 총 공모가격이다. 기관·자문계좌 할인, 할인발행 등으로 서로 다를 수 있다. `issue_price_per_1000`과 `estimated_value_per_1000`은 단위를 확인한 값만 사용한다. 다른 단위의 추정가치를 1,000달러당 값으로 가정하지 않는다.

CSV의 `*_pct`는 퍼센트포인트다. 10.75는 10.75%다. 제공 XLSX에서는 같은 값을 0.1075로 저장하고 10.75%로 표시한다. `participation=2`는 2배다. 결측은 빈칸이며, 0·해당 없음·미검출을 같은 의미로 취급하지 않는다. `missing_reasons`와 데이터사전을 확인한다.

가격–최초 추정가치 차이는 발행사 순이익이 아니다. 발행자·보증인 신용위험과 중도매도 가격위험이 있다. 쿠폰 관찰, 원금손실 barrier 관찰, 기초자산 하락폭을 구별한다. 예정 결제일을 실제 결제 완료로 읽지 않는다.

쿠폰 비교 후보는 동일 구조·기초자산·유사 만기·주기·memory·자동콜·barrier와 관찰방식이 맞고 필요한 값이 있는 집합으로 제한한다. 조기상환 유예기간 등 나머지 조건의 원문 대조가 필요하므로 인과적 가격분석이나 상품 우열 평가로 확대하지 않는다.
