# 신한은행 FE/RM AI Finance 실습 — Claude판

- 일정: **2026년 11월 28일, 12월 5일** 각 3시간 / 장소: 연세대학교
- 참가자: 신한은행 FE/RM, **Claude Pro 개인 구독**, 개인 노트북, **Azure 무료 계정**(사전 과제)
- 원본 수업안: Dropbox `JPMorgan_424B2_AI_Finance_수업자료` (ChatGPT+Excel판). 분모·근거·검증·고객 설명의 원칙과 평가 기준은 유지한다.

## 이 수업의 줄거리

> **내 Azure에 DB를 직접 만들고 → 공시를 넣고 → 검색 품질을 재고 → 벡터로 개선하고 → 그 DB로 JPM 상품군 전체를 분석한 뒤 → 상품 하나를 골라 가격을 매기고 새 상품을 설계한다.**

강사가 만든 DB를 빌려 쓰지 않는다. 수강생 각자의 Azure 구독에 PostgreSQL(pgvector)과 Azure OpenAI가 생기고, Claude Code가 데이터를 넣고, Claude 채팅은 커넥터(MCP)로 그 DB에 질문한다.

```
Dropbox 원문 (2026-09, 1,890건) ─▶ Claude Code (내 노트북) ─▶ 내 Azure PostgreSQL ◀─ 내 MCP 서버 ◀─ Claude 채팅·프로젝트
                                        │                       ▲  (키워드 색인 + pgvector)
                                        └─▶ 내 Azure OpenAI ────┘  (임베딩)
```

## 수업을 마치면 참가자는

1. 공시 원문에서 **문서와 상품을 구분**하고, 예비·최종을 구별한다.
2. 클라우드에 **DB와 AI 서비스를 직접 배포**하고, 데이터를 적재한다.
3. AI 추출 결과를 **정답과 채점**하고, 규칙 하나를 고쳐 정확도를 올린다.
4. **키워드·벡터·하이브리드 검색**을 같은 문항으로 채점해, 무엇이 왜 좋아지는지 숫자로 말한다.
5. 분모를 밝혀 **상품군 전체**를 분석하고, 교란 효과를 찾아낸다.
6. 상품 하나를 **원문 근거 → 지급 구조 → 몬테카를로 가격**까지 분석하고, **새 상품을 설계**하거나 **고객 설명서**를 만든다.
7. 근거가 부족하면 **결론을 보류**한다.
