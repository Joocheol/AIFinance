## 1. Claude Pro 확인 (5분)

1. [claude.ai](https://claude.ai) 로그인 → 왼쪽 아래 이름 → 요금제가 **Pro**인지 확인
2. **아티팩트**가 켜져 있는지 확인 (바로 가기: `https://claude.ai/settings/capabilities`)
   - 한국어 화면: **설정 → 기능 → 비주얼 → 아티팩트** / 영어 화면: **Settings → Capabilities → Artifacts**
   - **아티팩트**: Claude가 대화 옆 별도 창에 띄우는 결과물(계산기·문서·차트). 2일차에 새 상품 설계서와 고객 설명서를 만듭니다.
3. 시험 질문: *"1부터 10까지 제곱한 표를 만들고, 그 표를 Excel 파일로 저장해줘."* → Excel 파일을 내려받을 수 있으면 성공

## 2. Claude Desktop 설치, Code 탭과 Python 준비 (15분)

1. [claude.ai/download](https://claude.ai/download)에서 Windows/Mac용 **Claude Desktop** 설치 → 같은 계정으로 로그인
2. **`jpm-class`** 폴더를 만듭니다.
   - Mac: Finder → **문서(Documents)** 안에 만들기
   - Windows: **`C:\Users\내이름\jpm-class`** 에 만들기 (탐색기 주소창에 `%USERPROFILE%` 입력 → 새 폴더).
     "문서" 폴더는 OneDrive와 동기화되는 경우가 많아 파일 잠금·경로 문제가 생길 수 있으니 피합니다.
   - Windows는 Git 없이도 Code 탭이 동작합니다(2026-11 확인).
3. Claude Desktop 상단의 **Code** 탭 → 폴더 선택에서 `jpm-class` 지정
4. 시험 요청 두 가지를 차례로 보냅니다.
   - *"이 폴더에 hello.txt 파일을 만들고 오늘 날짜를 적어줘."* → 파일이 생기면 성공
   - *"Python 패키지 관리자 uv가 설치되어 있는지 확인하고, 없으면 공식 설치 방법으로 설치해줘. 설치 후 `uv run --python 3.12 python --version`을 실행해 결과를 보여줘."* → `Python 3.12.x`가 보이면 성공
     (수업 실습 스크립트를 이 방법으로 실행합니다. 노트북에 Python이 없어도 uv가 알아서 받습니다.)

> Code 탭은 Claude가 **내 노트북에서 직접 파일을 만들고 명령을 실행**하는 기능입니다. Claude가 무언가를 실행하려 할 때마다 허락을 묻습니다. 무엇을 하려는지 읽고 허락하세요.

## 3. Azure 무료 계정 만들기 (10분) — **11월 16일 이후에** 만드세요

무료 계정의 크레딧과 무료 기간은 **가입 후 30일**입니다. 12월 5일 수업까지 유효하도록 **11월 16일~26일 사이**에 가입하세요.

1. [azure.microsoft.com/free](https://azure.microsoft.com/free) → **무료로 시작**
2. Microsoft 계정으로 로그인(없으면 새로 만들기)
3. **휴대폰 인증** → **카드 인증**
   - 본인 확인용입니다. 무료 계정에서는 직접 "종량제로 업그레이드"하지 않는 한 **요금이 청구되지 않습니다.**
   - 카드 인증이 실패하면 다른 카드(해외 결제 가능 카드)로 다시 시도하세요.

5. 4번 화면을 캡처해 둡니다.

> 수업 1일차에 이 계정으로 **내 DB(PostgreSQL)와 AI 임베딩 서비스, MCP 서버**를 버튼 하나로 만듭니다. 지역은 **Japan East**를 씁니다. 한국 지역에서는 무료 등급 DB가 만들어지지 않습니다.

- **Azure 가입 후 요금이 나오나요?** 무료 계정은 업그레이드하지 않으면 청구되지 않습니다. 수업에서 만드는 DB(B1ms)는 무료 계정의 12개월 무료 대상이고, 임베딩 비용은 한 달 치 공시 기준 약 $0.22로 무료 크레딧 안에서 처리됩니다. 2일차 마지막에 정리 방법을 함께 합니다.

- **Claude 사용량 한도는?** Pro는 일정 시간당 사용량 한도가 있습니다. 활동마다 **새 대화**를 열고, 큰 파일을 Claude에 직접 올리지 마세요. 큰 데이터는 Claude Code가 DB에 넣고, Claude는 필요한 부분만 조회합니다.
