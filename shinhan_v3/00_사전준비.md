**요청 2**
```
Azure CLI 가 설치되어 있는지 확인하고, 없으면 이 운영체제에 맞는 공식 방법(Windows: winget, Mac: Homebrew)으로 설치해줘.
설치 후 `az version` 결과를 보여줘. 로그인(az login)은 내가 직접 할게.
```

> **Windows**: 5·6번에서 "앱이 디바이스를 변경하도록 허용하시겠습니까?" 창이 뜨면 **예**를 누릅니다. 설치가 끝났는데 Claude가 `uv`·`az`를 "찾을 수 없다"고 하면 VS Code를 **완전히 닫았다 다시 열고**(창 하나만 닫으면 안 됨) 같은 요청을 다시 보냅니다.

> **Mac에 Homebrew가 없으면** Claude가 "관리자 비밀번호가 필요해 설치하지 못했다"고 답합니다. 정상입니다. Claude는 비밀번호를 입력할 수 없습니다. 이때는 VS Code 터미널(**터미널 → 새 터미널**)에서 아래를 **직접** 실행합니다. 중간에 Mac 로그인 비밀번호를 묻고, 처음이면 개발자 도구(Command Line Tools) 설치로 10분쯤 걸릴 수 있습니다.
> ```
> /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
> ```
> 설치가 끝나면 화면 끝 **Next steps** 아래에 `echo`로 시작하는 줄 두 개와 `eval`로 시작하는 줄 하나가 나옵니다. 화면에 나온 그대로(내 Mac 이름이 들어 있음) 한 줄씩 복사해 같은 터미널에 붙여 넣고 Enter를 누릅니다. `brew --version`이 나오면 성공입니다. (Next steps가 안 나오는 Intel Mac은 건너뜁니다.) 그다음 VS Code를 **완전히 종료**(⌘Q)했다 다시 열고, Claude Code 패널에 요청 2를 다시 보냅니다.

> Claude Code는 명령을 실행하기 전에 허락을 묻습니다. 무엇을 하려는지 읽고 허락합니다.
> 수업은 **공개된 SEC 공시**만 다룹니다. 회사 자료·고객 정보는 Claude나 Azure에 올리지 않습니다.
> `.env`는 비밀 파일입니다(이메일, 이후 DB 비밀번호와 키). 채팅에 붙여 넣거나 Claude에게 열어 보라고 하지 않습니다.
> SEC는 자동으로 공시를 받는 프로그램에 연락처를 밝히라고 요구합니다. 이메일은 SEC에 보내는 요청의 머리글에만 쓰입니다.
