## 활동 1. [경험 1] SEC EDGAR에서 공시 찾기 (15–35분)

1. 브라우저에서 [EDGAR 전문 검색](https://www.sec.gov/edgar/search/)을 엽니다.
2. 검색어 `48136HP69` → 424B2가 **2건** 나옵니다 (2025-10-09, 2025-10-20). **둘 다 열어** 맨 위 문구를 비교합니다.
   - 결과를 누르면 미리보기 창이 하나만 뜹니다. 미리보기 창 오른쪽 위 **Open document**를 누르면 새 탭으로 열립니다. 두 건 모두 이렇게 새 탭으로 열어 탭을 오가며 비교하세요.
   - 각 탭에서 **Ctrl+F(⌘F)** 로 `not complete`, `PRELIMINARY`, `At least`를 찾아보세요.
   - 어느 쪽이 예비이고 어느 쪽이 최종인가요? 판단 근거 문구는? → 진단 3번 "공시 2건이 같은 상품일 수 있나"의 실물입니다.

## 활동 2. [경험 2] Claude로 추출하고, 다른 조가 검증하기 (35–70분)

### 2-1. 원문을 Claude에 주기 (5분)
1. 활동 1에서 연 `0001213900-25-100323` 원문 화면에서 **인쇄(Ctrl+P / ⌘P) → PDF로 저장**
2. claude.ai **새 대화** → PDF 첨부 → 아래 프롬프트

### 2-2. 추출 프롬프트 (복사해서 사용)

```
첨부한 공개 SEC 문서만 사용해 표를 작성해줘. 필드: 문서유형, 실제 발행자, 보증인, CUSIP/ISIN,
pricing/trade/예정 issue/maturity date, 통화, 총 공시 원금, 1,000달러당 발행가격과 최초 추정가치,
기초자산, 쿠폰 조건·주기·memory, 자동콜/발행자 임의콜, barrier/buffer/cap/participation,
원금 상환조건, 쿠폰 관찰과 원금손실 barrier 관찰방식.
각 값에 원문 근거 문장과 위치를 붙여줘. 없는 값은 null, 확신이 낮으면 "검토 필요"로 표시해.
1,000달러당 금액과 총액, 연율과 회당율을 구분해.
```

### 2-3. 교차 검증 (15분)
옆 조와 **추출표를 바꿉니다.** 받은 표와 원문 PDF를 함께 Claude 새 대화에 넣고:

```
원문과 추출표를 비교해 오류 후보만 찾아줘. 문서유형, 발행자/보증인, 숫자의 단위, 예정일과 실제일의 구별,
쿠폰의 연율/회당율, 단일기초/바스켓/worst-of, 관찰방식, 다상품 분리를 우선 점검해.
각 오류마다 기존값, 수정값 또는 null, 근거 문장을 제시해.
발행가격과 추정가치의 차이를 발행사 순이익으로 부르지 마.
```

그다음 **사람이 원문에서 직접** 확인합니다. Claude의 지적이 맞는지도 판정하세요.
