## 활동 9. [경험 9] 몬테카를로로 상품 가격 매기기 (85–110분)

대상: XLF 연계 Auto Callable Contingent Interest Notes (CUSIP 46660JDY5, accession 0001839882-26-005594)

| 조건 | 값 |
|---|---|
| 기초자산 / 최초가 | XLF (Financial Select Sector SPDR ETF) / $53.41 |
| 가격결정일 → 만기 | 2026-01-27 → 2027-02-11 |
| 관찰 | 분기 (첫 관찰일부터 자동콜 가능) |
| 조건부 쿠폰 | 연 8.0% (분기 2.0%), 쿠폰 배리어 최초가의 80.99% |
| 자동콜 | 관찰일 종가 ≥ 최초가 100% |
| 만기 원금 | 종가 ≥ 80.99% → 원금+쿠폰, 아니면 원금 × (종가/최초가) |

## 활동 11. [경험 11] Claude Code가 SEC 원문을 직접 받아 오기 (135–160분)

> 같은 강의실의 모든 요청이 하나의 IP로 SEC에 갑니다. **강사가 부르는 조 순서대로, 한 사람이 원문 1건만** 받습니다.

Claude Desktop → **Code** 탭 → 폴더 `jpm-class`

**① 의도된 실패 (네트워크 없음)**
```
SEC에서 공시를 받는 파이썬(또는 PowerShell/curl) 스크립트를 만들어줘. 규칙: 요청 전에 환경변수 SEC_USER_AGENT에
"이름 이메일" 형식의 연락처가 있는지 먼저 검사하고, 없으면 네트워크 요청 없이 LOCAL_PREFLIGHT_CONTACT_MISSING을
출력하고 멈춰. 지금은 SEC_USER_AGENT 없이 실행해서 실패를 확인해줘.
```

**② 내 연락처 설정** — 이메일은 채팅에 쓰지 말고, 터미널에서 내가 직접 환경변수로 설정합니다.
(Windows PowerShell: `$env:SEC_USER_AGENT="Shinhan-class 내이름 내이메일"` / Mac: `export SEC_USER_AGENT="..."`)

**③ 원문 1건 받기** (조별 배정 accession)
```
배정받은 URL 하나만 요청 간격 1초 이상, 동시 요청 1개로 받아서 저장해줘. 403이나 429가 나오면 재시도하지 말고
즉시 멈춰. 받은 파일의 크기와 SHA-256 해시를 출력하고, 로그에 연락처를 남기지 마.
```

| 조 | CUSIP | URL |
|---|---|---|
| 1, 4 | 48136HP69 | https://www.sec.gov/Archives/edgar/data/19617/000121390025100323/ea0261807-01_424b2.htm |

**④ 같은 원문인가?** 내가 받은 파일의 SHA-256과 강사가 공개하는 Dropbox 수집본의 해시를 비교합니다.
