# 실습: Claude와 함께 SEC에서 공시 원문 한 달 치 받기

**목표**: JPMorgan이 2026년 10월에 낸 424B2 공시 원문을 **SEC에서 직접** 받는 코드를 Claude와 만들고, 내가 읽고, 내가 실행하고, 받은 것이 맞는지 확인합니다.
이 데이터가 이후 모든 실습(텍스트 변환 → 규칙 추출 → 상품 표 → 검색)의 출발점입니다.

| 할 일 | 어디서 | 시간 |
|---|---|---|
| 1. 연락처가 `.env`에 있는지 확인 (사전 준비 9) | 메모장 | 1분 |
| 2. Claude에게 코드 만들게 하기 | Code 탭 | 10분 |
| 3. 코드를 읽고 요구사항 확인 | Code 탭 | 10분 |
| 4. 목록만 받기, 원문 3건만 받기 (시험) | Code 탭 | 5분 |
| 5. 10월 전체 받기 (백그라운드, 약 20분) | Code 탭 | 기다리는 동안 다음 설명 |
| 6. 받은 것 검증 | Code 탭 | 5분 |

> **SEC 공정 접근 규칙**: 한 IP에서 초당 10건까지. 넘으면 SEC가 그 IP를 10분 이상 막습니다(403). 이 강의실은 노트북마다 IP가 달라 각자 받을 수 있지만, 내 코드는 **초당 2건**으로 여유 있게 받습니다.

---

## 1. 연락처가 `.env`에 있는지 확인 (사전 준비 9에서 적어 옴)

SEC는 자동으로 받는 프로그램에 **연락처(이름과 이메일)** 를 밝히라고 요구합니다. 연락처가 없으면 403으로 거부합니다.

사전 준비에서 `문서/jpm-class/jpm_kit/.env`에 이 한 줄을 적어 왔습니다. 메모장으로 열어 있는지만 확인합니다(없으면 지금 적습니다).

```
SEC_CONTACT=홍길동 gildong@example.com
```

이메일은 **채팅에 쓰지 않습니다.** 코드가 `.env`를 직접 읽습니다. Claude는 `.env`를 열지 않습니다(키트의 `CLAUDE.md` 규칙).

## 2. Claude에게 코드 만들게 하기

Claude Desktop → **Code** 탭 → 폴더 `jpm-class`. 아래 요구사항을 **그대로** 붙여 넣습니다.

```
jpm_kit/sec_oct.py 를 만들어줘. 아직 실행하지 마.
목적: JPMorgan이 2026-10-01 ~ 2026-10-31에 SEC에 제출한 424B2 공시 원문을 받는다.

요구사항
1. 대상 목록: https://data.sec.gov/submissions/CIK0000019617.json (JPMorgan Chase & Co.)과
   CIK0001665650.json (발행 자회사)의 filings.recent 에서 form 이 424B2 이고 filingDate 가 10월인 것.
   같은 공시가 두 회사에 함께 등록되므로 accessionNumber 로 합친다.
2. 원문 주소: https://www.sec.gov/Archives/edgar/data/19617/<accessionNumber에서 '-'를 뺀 것>/<primaryDocument>
3. 연락처: jpm_kit/.env 의 SEC_CONTACT 값을 User-Agent 로 쓴다. 값을 화면에 출력하거나 다른 파일에 쓰지 않는다.
   너(Claude)는 .env 를 열지 않는다. 코드가 실행될 때 읽는다.
4. 속도: 요청은 한 번에 하나씩, 초당 2건 이하.
5. 403 또는 429 를 받으면 즉시 전체를 멈추고 이유를 출력한다. 다른 방법으로 다시 시도하지 않는다.
6. 저장: jpm_kit/sec_oct/html/<accessionNumber>.html. 이미 있는 파일은 다시 받지 않는다(중단 후 이어 받기).
7. 기록: jpm_kit/sec_oct/filings.csv (accession, filingDate, 등록 회사, 원문 주소)와
   jpm_kit/sec_oct/download_log.csv (accession, 결과, 바이트 수, sha256, 받은 시각).
8. 옵션: --list-only (목록만 만들기), --limit N (원문 N건만 받기).
9. 100건마다 진행 상황(받은 수, 경과 시간, 남은 시간 추정)을 한 줄로 출력한다.
10. Python 표준 라이브러리만 쓰고, 실행은 `uv run jpm_kit/sec_oct.py` 로 한다.
다 만들면 코드가 위 10가지를 각각 어디서 지키는지 줄 번호로 알려줘.
```

## 3. 코드를 읽고 요구사항 확인

Claude가 알려 준 줄 번호를 **직접 열어** 확인하고 표를 채웁니다. 하나라도 "아니요"면 Claude에게 고치게 합니다.

| # | 요구사항 | 지키나? | 줄 번호 |
|---|---|---|---|
| 1 | 두 회사 목록을 합친다 (한 회사만 보면 몇 건이 빠질까?) | | |
| 3 | 연락처를 출력하지 않는다 | | |
| 4 | 초당 2건 이하, 한 번에 하나 | | |
| 5 | 403·429면 즉시 멈춘다 | | |
| 6 | 이미 받은 파일은 건너뛴다 | | |

> 확인 질문: *"이 코드가 SEC에 보내는 요청을 하나씩 순서대로 말해줘. 10월 전체를 받으면 요청이 모두 몇 번이고 몇 분 걸려?"*

## 4. 시험: 목록만, 그다음 3건만

```
uv run jpm_kit/sec_oct.py --list-only
uv run jpm_kit/sec_oct.py --limit 3
```

| 확인 | 내 값 |
|---|---|
| 10월 424B2 공시 수 | |
| 그중 두 회사에 함께 등록된 수 | |
| 받은 3건의 accession | |
| `html` 폴더에서 1건을 브라우저로 열었을 때 보이는 제목 | |

403이 나오면 **그 자리에서 멈추고 손을 듭니다.** 다시 실행하지 않습니다.

## 5. 10월 전체 받기

Code 탭에서:
```
jpm_kit/sec_oct.py 를 백그라운드로 실행하고, 진행 상황을 주기적으로 알려줘.
```

초당 2건이면 약 1,900건에 20분 남짓 걸립니다. 노트북 전원을 연결하고 덮지 않습니다. 중간에 멈추면 같은 명령을 다시 실행합니다(이어 받기). 기다리는 동안 다음 실습(HTML을 텍스트로 바꾸기)의 설명을 듣습니다.

> 403이 나오거나 시간 안에 못 받으면: 강사가 올린 [`10월_원문.zip`](https://www.dropbox.com/scl/fi/a7njti2aj7789ccrj0cyw/10-_.zip?rlkey=tk8t7s50x2vsotvejaeh8vfit&dl=1)(51MB, 받은 파일 이름이 `10-_.zip`처럼 보일 수 있음)을 `jpm_kit/sec_oct/` 폴더에 풉니다. `filings.csv`와 `html/`(1,859건)이 생깁니다. 검증(6)은 똑같이 합니다.

## 6. 받은 것이 맞는지 검증

```
uv run jpm_kit/check_oct.py
```

키트의 검증 스크립트가 내 `sec_oct/` 를 **강사가 같은 날 받은 목록과 원문**에 대조합니다.
SEC는 원문을 보낼 때마다 끝에 봇 차단용 `<script>` 한 줄을 바꿔 붙이므로, 그 줄만 빼고 비교합니다.

| 확인 | 내 값 |
|---|---|
| 목록: 강사 목록과 같은 accession 수 / 빠진 수 / 더 있는 수 | |
| 원문: 같은 파일 수 / 다른 파일 수 / 없는 파일 수 | |
